# AR Furniture Placement

## Overview
AR Furniture Placement is a Unity AR application that allows users to place virtual furniture onto detected real-world surfaces using their mobile device. Users can select furniture, place it in the environment, and interact with it through simple controls.

## Features
- Plane detection using AR Foundation
- Furniture selection
- Tap to place furniture
- Select placed furniture
- Rotate furniture
- Scale furniture
- Move furniture
- Delete furniture
- Reset the scene
- Main menu with instructions

## Requirements
- Unity 6
- AR Foundation
- ARCore XR Plugin
- Android device with ARCore support

## How to Run
1. Clone this repository.
2. Open the project in Unity.
3. Open the **MainMenu** scene.
4. Build and run the project on an ARCore-supported Android device.
